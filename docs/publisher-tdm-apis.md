# Publisher full-text APIs (all public, worth a bookmark)

These are the sanctioned routes. Register for your own credentials:

| Publisher | Route | How to get access |
|---|---|---|
| **Unpaywall** | `api.unpaywall.org/v2/{doi}?email=you@x` | Free. Just pass your email. OA only. |
| **Elsevier TDM** | `api.elsevier.com/content/article/doi/{doi}` with `Accept: application/pdf` — do **not** add `view=FULL`; it's unnecessary for PDF and gets rejected (`400 INVALID_INPUT`) for a subset of articles, masquerading as a coverage gap. **Read the `X-ELS-Status` response header**: for a DOI the key is not entitled to, the API still answers HTTP 200 with a real PDF — but only the first page — and announces it as `WARNING - Response limited to first page because requestor not entitled to resource` (entitled: `OK`). The Article Entitlement API (`/content/article/entitlement/doi/{doi}`) would be the clean check but returns `403 AUTHENTICATION_ERROR` for TDM keys. | Register at [dev.elsevier.com](https://dev.elsevier.com); header `X-ELS-APIKey`. Off-campus paywalled content also needs an `X-ELS-Insttoken` from your library. |
| **Wiley TDM** | `api.wiley.com/onlinelibrary/tdm/v1/articles/{doi}` | Accept the click-through at [static.wiley.com/tdm](https://static.wiley.com/tdm/); header `Wiley-TDM-Client-Token`. |
| **Springer** | `api.springernature.com/openaccess/json?q=doi:{doi}` | Register at [dev.springernature.com](https://dev.springernature.com). OA direct (`link.springer.com/content/pdf/{doi}.pdf`) worked with no key until 2026-09; since then every scripted request (any UA, with landing-page cookies, even a Chrome TLS fingerprint via curl_cffi) gets an HTTP 200 + 3 KB "Client Challenge" JS page. The API's own `url` values point at the same host. OA Springer/BMC articles are now fetched from PMC / Europe PMC; the rest need a real browser (layer 3). |
| **Crossref / Europe PMC** | metadata + OA full text | No key. Great for resolving and for PMC-hosted OA. With a PMCID the only script-usable PDF endpoint is Europe PMC's `europepmc.org/articles/{PMCID}?pdf=render` — `pmc.ncbi.nlm.nih.gov/articles/{PMCID}/pdf/` serves a reCAPTCHA page, and the Europe PMC REST `fullTextXML` is XML, not PDF. The render endpoint occasionally answers HTTP 500 and is fine minutes later; `_grab` retries a 5xx once. |
| **MDPI** | `mdpi-res.com/d_attachment/{j}/{j}-{vol}-{art:05d}/article_deploy/{j}-{vol}-{art:05d}.pdf` | No key. The publisher site (`www.mdpi.com/…/pdf`, also what Semantic Scholar hands out) is Cloudflare-403 to scripts; the CDN is not. `{j}` is the DOI's journal code (`life`, `ijerph`, `jcm`) **or** the journal's full name without spaces (`nutrients`, `sensors`, `antioxidants`) — `paper_fetch.py` tries both, volume from Crossref, article number = DOI digits after volume + 2-digit issue. 16/17 sampled DOIs hit on 2026-09-05. |
